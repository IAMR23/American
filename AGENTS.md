# Instrucciones de trabajo

Trabaja siempre usando CMD (`cmd.exe`).

Cuando necesites ejecutar npm, hazlo directamente en la terminal integrada con comandos como:

```cmd
npm install
npm run dev
npm run build
```

No abras el selector de tareas de npm, no uses "Run npm Script", no abras terminales emergentes, no inicies servidores automaticamente y no abras el navegador. Si necesitas ejecutar el proyecto, preguntame primero.

## Alcance de Bookstore

Cuando el usuario diga "trabaja en Bookstore", trabaja exclusivamente dentro de las carpetas `backend_boostore` y `frontend_bookstore`. No leas, modifiques ni ejecutes archivos o comandos en otras carpetas del proyecto, salvo que el usuario lo autorice explicitamente.
